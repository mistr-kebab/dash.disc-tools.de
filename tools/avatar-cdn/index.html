What is the Avatar CDN?

Discord stores user avatars, server icons, and banners on its content delivery network (CDN). The Avatar CDN tool extracts these URLs so you can download, share, or use them outside of Discord. Every Discord user and server has a unique hash that determines their avatar URL, and this tool retrieves it instantly.

Whether you need a friend's profile picture in high resolution, want to save a server icon for reference, or need to verify avatar changes over time, the Avatar CDN has you covered. It supports all standard image formats including animated GIFs.

Use Cases

  • Profile Archives — Save avatars of community members who've left your server
  • Design References — Use server icons and banners as inspiration for your own branding
  • Moderation — Document inappropriate avatars with links to the exact CDN file
  • Bot Development — Quickly verify avatar hashes and format URLs for your own Discord bots

How to Use

Invite the Disc-Tools bot to your server and run the slash command:

/avatar user: <@user>

You can pass a user mention for someone's profile picture, a guild ID for a server icon, or a user ID for global profile data including banners. The bot returns direct CDN links in multiple resolutions (16px to 4096px) in PNG, JPEG, WebP, and GIF formats.
