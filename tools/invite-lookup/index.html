Discord Invite Lookup

Resolve any Discord invite link to see server name, member count, channel destination, expiration date, and creator details — all from a single slash command.

Add Bot to Server

What is the Invite Lookup?

The Invite Lookup tool resolves any public Discord invite link and returns detailed information about the destination server. Just paste an invite code or full invite URL — the bot retrieves the server name, icon, member count (online and total), verification level, targeted channel, invite expiration date, and the Discord user who created the invite.

This is useful for vetting servers before joining, investigating suspicious invite links, or gathering information about communities. Unlike server lookups, invite lookups can resolve any public invite code even if the bot isn't in the target server, as long as the invite is still valid.

Use Cases

  • Server Vetting — Check a server's size, verification level, and content before clicking an invite
  • Moderation — Investigate invite links posted in your community to detect spam or scam servers
  • Competitor Research — Estimate the size and activity level of other Discord communities
  • Expiration Tracking — See when a temporary invite will expire before sharing it

How to Use

Invite the Disc-Tools bot to your server and run:

/invite-lookup invite: discord.gg/example

You can pass the full invite URL (e.g. https://discord.gg/abc123) or just the invite code (abc123). The bot responds with a detailed embed showing server information, member counts, verification level, target channel, creator info, and expiry status. Vanity URLs like discord.gg/discord-developers are also supported.
