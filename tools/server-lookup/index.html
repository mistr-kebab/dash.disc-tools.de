Discord Server Lookup

Look up detailed information about any public Discord server — member count, owner, boost level, channels, roles, vanity URL, banner, and more from a single slash command.

Add Bot to Server

What is the Server Lookup?

The Server Lookup tool retrieves comprehensive information about any public Discord guild using its server ID. You get the server name, icon, banner, owner, member count, boost tier and count, channel and role counts, vanity URL code, description, verification level, and creation date. All of this is displayed in a clean, organized embed right in your Discord channel.

This tool is invaluable for server admins researching other communities, moderators investigating report claims, and users curious about a server's size and activity level. The lookup only works for servers the bot shares with you, or for public servers indexed by Discord's API — private server data is never exposed.

Use Cases

  • Server Research — Check a server's size and activity before joining or partnering
  • Moderation — Investigate server IDs reported by your community members
  • Growth Tracking — Monitor your own server's growth metrics over time using repeated lookups
  • Partner Vetting — Verify a partner server's member count and boost level before agreeing to cross-promotion

How to Use

Invite the Disc-Tools bot to your server and run:

/server-lookup guild_id: 123456789012345678

Enter a Discord server ID (18-19 digit number). You can get any server's ID by enabling Developer Mode in Discord settings and right-clicking the server icon. The bot returns a rich embed with all available server information including creation date, boost status, vanity URL details, and system channel configuration.
