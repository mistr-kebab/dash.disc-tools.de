Discord Webhook Manager

Send, edit, and delete Discord webhook messages with custom usernames, avatars, and rich embeds — full control over webhook content from a slash command.

Add Bot to Server

What is the Webhook Manager?

Discord webhooks are a powerful way to send automated messages into a channel — they can have custom names, avatars, and embed content. The Webhook Manager tool gives you complete control over webhooks directly from a Discord slash command. You can create a webhook, send messages through it, view existing webhooks, edit webhook names and avatars, and delete webhooks you no longer need.

Unlike many webhook tools that require external websites or complex API calls, the Webhook Manager runs entirely inside Discord. You can customize the message content, author, title, description, embed fields, color, thumbnail, image, footer, and timestamp — all through simple command parameters. It's ideal for server admins who want to automate announcements without writing code.

Use Cases

  • Automated Announcements — Create webhooks for welcome messages, rule posts, or update notifications
  • Custom Branded Messages — Send messages under a custom username and avatar for roleplay or themed channels
  • Cross-Server Communication — Bridge announcements between multiple Discord servers using webhooks
  • Bot Message Prototyping — Preview how webhook-delivered embeds will look before integrating them into your bot

How to Use

Invite the Disc-Tools bot to your server and run the slash commands:

/webhook create name: "Announcements" channel: #general
/webhook send content: "Hello world!" username: "Bot" avatar_url: https://...

The webhook command group includes subcommands for creating, listing, sending, editing, and deleting webhooks. To send messages, you can customize every aspect: plain text content, embed author/fields/colors/images, custom username and avatar URL, and TTS mode. All webhook management respects Discord's permission system — you need Manage Webhooks permission in the target channel.
