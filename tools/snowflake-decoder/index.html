Discord Snowflake Decoder

Decode any Discord snowflake ID into a human-readable timestamp. Find out exactly when a user account, server, channel, or message was created.

Add Bot to Server

What is the Snowflake Decoder?

Discord uses Twitter's snowflake format for all unique IDs — users, servers, channels, messages, roles, and emojis. Each snowflake contains an embedded timestamp indicating exactly when that entity was created, down to the millisecond. The Snowflake Decoder extracts this timestamp and converts it into a readable date and time.

This is one of the most useful Discord utilities: you can determine a user's account age, see when a server was founded, check how old a channel is, or find out the exact second a message was sent. The decoder works with any valid Discord snowflake ID from the Discord epoch (January 1, 2015) onward.

Use Cases

  • Account Age Verification — Check how old a user's Discord account is to spot new alt accounts
  • Server Age — Find out exactly when a Discord server was created from its guild ID
  • Message Forensics — Determine the exact timestamp of a message even after it's edited
  • Bot Development — Debug and validate snowflake generation in your own applications

How to Use

Invite the Disc-Tools bot to your server and run:

/snowflake id: 123456789012345678

Enter any Discord ID — copy it by enabling Developer Mode in Discord settings, then right-click any user, server, channel, or message and select "Copy ID." The bot returns the exact UTC creation date and time, a relative timestamp (e.g. "3 years ago"), and a Discord-formatted dynamic timestamp you can use in messages.
